# Mathfolio for Obsidian 0.1.8 — development draft

- Fix startup in PC browser web sessions by replacing Node-specific decompression with browser gzip streams.
- Update to Mathfolio SDK 0.1.2-rc2: Ctrl/Command+click selection, worksheet select-all, and web cuts that wait for clipboard success.
- Keep three-file installation, bundled offline binary assets and a per-file 5 MB limit.

Mobile is outside this version's support scope. This is a local development build; no public release has been published. Final publication requires the SDK release dependency and release gate checks described in RELEASING.md.
