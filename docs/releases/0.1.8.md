# Mathfolio for Obsidian 0.1.8

- Improve PC browser web-session compatibility with browser-native gzip asset loading.
- Update to the released Mathfolio SDK 0.1.2: CAD marquee/group editing, Ctrl/Command+click selection, worksheet select-all and web cuts that wait for clipboard success.
- Preserve normal formula/text editing shortcuts, saved calculation results, local Worker calculation and offline assets.
- Keep standard three-file installation and each file below 5 MB.
- Verify calculation, save/reopen, PDF, searchable settings, keyboard input and external-edit recovery in isolated Linux Desktop and PC browser Vaults.

Install `main.js`, `manifest.json` and `styles.css` together. Reload the plugin or refresh the web session after updating. Minimum Obsidian version: 1.14.4. Mobile remains outside the support scope.

The plugin and SDK use AGPL-3.0-only; bundled third-party notices remain available in settings. Build-tool updates and the narrowly reviewed legacy minimatch audit finding are recorded in [the dependency audit review](https://github.com/Glaysia/obsidian-mathfolio/blob/0.1.8/docs/DEPENDENCY-AUDIT.md). This is not a claim that raw npm audit reports zero findings.
