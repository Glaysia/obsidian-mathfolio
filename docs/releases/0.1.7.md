# Mathfolio for Obsidian 0.1.7

This update addresses the 0.1.0 community review findings and verifies the complete desktop integration.

- Pinned Mathfolio SDK 0.1.1 release dependency with TypeScript declarations and runtime validation at settings/Worker boundaries.
- Searchable declarative settings, window-owned timers, Obsidian DOM helpers and CSS without !important.
- English README with a Korean guide.
- Folder-by-folder worksheet browsing and recovery-folder-only lookup, without Vault-wide enumeration.
- Offline compressed assets: main.js is 4.92 MB and styles.css is 2.74 MB, each below 5,000,000 bytes. The desktop runtime decodes WASM/Worker assets locally; font data is in styles.css.
- GitHub build provenance attestations for main.js and styles.css. Only the three supported Obsidian installation files are attached.

## Install

Download main.js, manifest.json and styles.css together into `<vault>/.obsidian/plugins/mathfolio/`, then enable or reload Mathfolio. Preserve a backup of existing plugin files before replacing them. The matching styles.css is required for the bundled font. Desktop only; minimum Obsidian 1.14.4.

## Verification

Tested in a separate Linux / Obsidian 1.14.5 Vault using only the three release installation files: real WASM and calculation Worker, keyboard entry, calculation, saved result cache after session/app restart without automatic recalculation, PDF generation, settings and external-edit conflict recovery. The user also confirmed successful use. Type check, strict lint, nine regression tests and dependency audit pass.

Windows, physical Korean IME workflows, actual popout windows and crash/power-loss recovery remain unverified. Community review must run again to confirm its findings are resolved.

Plugin versions 0.1.1 through 0.1.6 are sequential development commits; this is the only new plugin tag and public release. SDK versioning is independent. Source and license: AGPL-3.0-only; see sdk.lock.json and the bundled notices for dependency provenance and third-party terms.
