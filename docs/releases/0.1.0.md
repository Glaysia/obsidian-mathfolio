Mathfolio의 Rust 워크시트 편집기와 계산 엔진을 Obsidian에서 사용하는 첫 공개 버전입니다.

- `.mathfolio`, 이전 `.mathcraft`, `.mcdx` 파일 열기와 편집
- 수식 계산, 단위·행렬 연산, 자동 저장과 수동 저장
- 외부 파일 변경 감지와 미저장 편집의 복구 사본
- 벡터 PDF 및 MCDX 내보내기
- Obsidian 테마 연동, Light·Dark·Nord 설정
- WASM·계산 Worker·한글 글꼴·라이선스를 `main.js`에 내장

Linux / Obsidian 1.14.5의 실제 b2 Vault에서 편집·계산·저장·재열기·PDF·충돌 복구를 확인했고 사용자 실사용 확인을 받았습니다. Windows·물리 한글 IME·강제 종료 복구는 아직 검증하지 않았습니다. Mobile은 지원하지 않습니다. 최소 앱 버전은 1.14.4입니다.

플러그인과 자체 코드는 AGPL-3.0-only이며, 포함된 제3자 구성요소는 각자의 라이선스를 유지합니다. 고지 전문은 플러그인 설정에서 볼 수 있습니다. Mathfolio SDK 0.1.1 / protocol 1의 원본 커밋과 WASM SHA-256은 이 태그의 `sdk.lock.json`에 고정되어 있습니다.

수동 설치: Vault의 `.obsidian/plugins/mathfolio/`에 `main.js`, `manifest.json`, `styles.css`를 넣고 커뮤니티 플러그인에서 활성화합니다. 기존 파일을 교체하기 전에 백업하세요. 커뮤니티 목록 등록은 별도 절차입니다.
